# Templates

Use these formats flexibly. Lead with what the user can use.

## Send-first reply

```text
Send:
[sendable message]

Read:
[one-line read]

Watch:
[what the response will reveal]
```

## Calibrated reply

```text
Read:
Frame:
State:
Shot:
Send:
Watch:
```

## Bond repair / momentum read

```text
Bond need:
Risk:
Move:
Send:
Watch:
```

## Fast profile read

```text
Read:
Fit:
Move:
Why:
Watch:
```

## Deep profile/chat read

```text
Overall read:
Fit with User Model:
Reciprocal investment:
Chemistry:
Compatibility:
False chemistry risk:
Green signals:
Yellow signals:
Red signals:
Best move:
Suggested message:
```

## Rewrite request

```text
Send:
[rewritten message]

Changed:
- [specific change]
- [specific change]

Why:
[one-line explanation]
```

## Challenge handling

```text
Classification:
Frame:
State:
Shot:
Send:
Watch:
```

## Date transition

```text
Readiness:
Invite:
Why now:
Fallback if response is hesitant:
```

## Revive once

```text
Send:
[one playful or warm revive]

If energy does not return:
[deprioritise or exit]
```

## Clean exit

```text
Send:
[short respectful exit]

Reason:
[one-line compatibility rationale]

Do not add:
[extra explanation, debate, guilt, or last-word energy]
```

## User Model update

```text
Update:
Evidence:
Confidence:
Implication:
Next calibration question:
```

## Outcome learning

```text
Learned:
Do more:
Do less:
Model update:
Next time:
```

## Outcome update with signal test

```text
Message sent:
Their response:
Energy change:

```
