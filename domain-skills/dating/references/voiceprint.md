# Voiceprint

Use this file to make drafts sound like the user rather than merely polished.

## Voiceprint template

```text
User Voiceprint

Sentence rhythm:
Typical length:
Directness:
Warmth:
Edge:
Humour:
Flirt style:
Question style:
Emoji/punctuation:
Words/phrases that sound natural:
Words/phrases to avoid:
Too much:
Too little:
Example messages that feel like the user:
Example messages that do not feel like the user:
```

## Calibration process

Ask for 5-10 messages the user has sent or would send. Extract:
- cadence;
- compression level;
- playfulness;
- directness;
- flirtation level;
- emotional openness;
- specificity;
- how the user signals interest;
- how the user exits or sets limits.

## Rewrite pass

Before finalising any draft, check:
- Would the user actually send this?
- Is the sentence length natural for them?
- Is the edge level calibrated?
- Does it sound too polished, too soft, too clever, too formal, or too explanatory?
- Does it preserve the user's real intent?

## Output when calibrating voice

```text
Voice read:
Keep:
Reduce:
Add:
Draft in your voice:
```

## High-performance voice target

Specific, natural, warm, lightly charged, and congruent with the user's actual tone.
