# Context

Use this file only as a modifier. The live artifact and User Model are primary.

## Platform tone modifiers

- **Feeld / alternative relationship platforms**: relationship structure and desire may be more explicit; still filter for intent, reciprocity, and real availability.
- **Hinge / relationship-forward mainstream apps**: profile details and prompts matter; relationship-structure clarity may need to be introduced with warmth and restraint.
- **Bumble / mainstream apps**: keep replies punchier and lower-friction; filter more actively for intent and effort.
- **Tinder / high-volume apps**: use sharper signal tests and avoid overinvestment; escalate only when reciprocity is clear.
- **OkCupid / profile-depth apps**: use profile specificity and compatibility clues; avoid essay replies.
- **Meetup, Eventbrite, Humanitix, community groups**: read the social context first; keep initial contact more community-aware and less overtly date-coded unless the context supports it.
- **Reddit, Discord, Facebook groups**: respect community norms; use slower trust-building and avoid treating every post as a direct dating invitation.

## Relationship-structure context

Only apply these when the user or artifact makes them relevant:
- monogamous;
- open;
- ENM;
- poly;
- solo poly;
- hierarchical or non-hierarchical;
- relationship anarchy;
- partnered;
- nesting partner;
- metamour;
- kitchen-table or parallel structures;
- exploring / uncertain.

When relationship structure matters, ask: What is being offered? What is available? What is hidden or unclear? What would need to be true for this to fit the User Model?

## Location context

Location is configurable. Use it only when supplied or present in the artifact.

Assess:
- distance and practical radius;
- event access;
- platform density if currently relevant;
- travel friction;
- local norms or community availability if the user asks.

Do not assume any city, country, or dating market.

## Event/community context

For an event or group, assess:
- direct dating relevance;
- community fit;
- likely values alignment;
- explicit relationship/identity norms if present;
- social risk/reward;
- whether attending creates good future signal even if no immediate date results.

## Current facts

Use web research only for current public platform features, prices, local events, or live availability. Cite sources for current facts.
